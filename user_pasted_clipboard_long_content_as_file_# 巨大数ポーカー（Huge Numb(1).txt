
# 巨大数ポーカー（Huge Number Poker）— 実装プロンプト

## 1. 前提・使用スキル
- **UIフレームワーク**: `game-ui-template-skill.md`
- 以上のスキルを元に全体的なUIを決定

---

## 2. ゲーム概要
ポーカーの駆け引き（チップ・ベット・ブラフ）と、配られたカードから数式を組んで巨大数を作るパズルを融合させたゲーム。

- 配札：各プレイヤー7枚
- 使用：7枚の中から**5枚以下**を自由に選択して数式を構築
- カード連結禁止（2と3をくっつけて「23」にするのは不可）
- 勝敗：ショーダウン時に数式の評価値が最大のプレイヤーが勝利。同値の場合は山分け。

---

## 3. データモデル

### 3.1 カード定義
```typescript
type CardType = 'number' | 'operator';

type Card = {
  id: string;
  type: CardType;
  value: number | string;  // number: 2-9, string: '+', '*', '^', '!', 'P', '↑↑'
  display: string;         // 表示用文字
  suit?: string;           // UI用（任意）
};

// デッキ構成（1デッキあたりの目安。調整可能）
// 数字カード: 2,3,4,5,6,7,8,9 を各4枚 = 32枚
// 演算子カード:
//   1(+)   : 4枚
//   10(×)  : 4枚
//   11(^)  : 4枚
//   12(!)  : 4枚
//   13(P)  : 4枚
//   Joker(↑↑): 2枚
```

### 3.2 プレイヤー
```typescript
type Player = {
  id: string;
  name: string;
  chips: number;           // 残りチップ
  hand: Card[];            // 手札（7枚）
  isDealer: boolean;
  isActive: boolean;       // false = フォールド済み
  currentBet: number;      // 今ラウンドの場に出しているチップ
  totalBet: number;        // ポットに入れた合計（表示用）
  formula?: FormulaSubmission; // 提出した数式（ショーダウン時に公開）
};
```

### 3.3 数式提出データ
```typescript
type FormulaSubmission = {
  usedCards: Card[];       // 実際に使用したカード（5枚以下）
  formulaString: string;   // 数式の文字列表現（例: "(5+3)^2"）
  playerDeclaredResult: string; // プレイヤーが入力した「答え」
  systemEvaluatedResult?: string; // システムが計算した答え
  isCorrect: boolean;      // プレイヤーの答えとシステムの答えが一致するか
  isValid: boolean;        // 構文として有効か
};
```

### 3.4 ゲーム設定
```typescript
type GameConfig = {
  initialChips: number;    // デフォルト 1000
  smallBlind: number;      // デフォルト 10
  bigBlind: number;        // デフォルト 20
  ante: number;            // デフォルト 5
  betTimeLimit: number;      // デフォルト 10（秒）— 通常プレイヤーのアクション制限時間
  dealerTimeLimit: number;   // デフォルト 20（秒）— 親（ディーラー）専用のアクション制限時間
  levelUpHands: number;    // 何ハンドごとにブラインド倍にするか。デフォルト 5
  deckCount: number;    // デフォルト 1。使用するデッキの組数
};
```

### 3.5 ゲーム状態（State Machine）
```
'SETTING'      → 設定画面
'DEALING'      → カード配布アニメーション
'BETTING_1'    → 1回目のベットラウンド
'EXCHANGE'     → カード交換フェーズ
'BETTING_2'    → 2回目のベットラウンド
'CALCULATION'  → 数式構築・結果入力フェーズ
'SHOWDOWN'     → ショーダウン（公開・比較）
'SETTLEMENT'   → 精算・次ハンドへ
```

## 4. ゲームフロー詳細

### 4.1 設定画面（SETTING）
- 入力項目:
  - プレイヤー数（2〜6）
  - 初期チップ（デフォルト1000）
  - 小ブラインド（デフォルト10）
  - 大ブラインド（デフォルト20）
  - アンティ（デフォルト5）
  - ベット制限時間（デフォルト10秒）
  - レベルアップ間隔（デフォルト5ハンド）
- **自動連動**: 初期チップを変更した際、小ブラインド・大ブラインド・アンティは**初期チップに対する比率を維持して自動変更**する（例: 1000→2000なら10/20/5が20/40/10に）。その後、各項目を手動で個別に上書き可能。
- 設定値はLocalStorageに保存し、次回起動時に復元。

### 4.2 配札（DEALING）
- 各プレイヤーに7枚ずつ配る。
- ディーラーボタンは時計回りに移動。
- アンティ（全員から設定額）をポットに徴収。
- 小ブラインド・大ブラインドを強制ベット。

### 4.3 ベットラウンド（BETTING_1 / BETTING_2）
- テキサスホールデムと同じポーカーアクションを実装:
  - **フォールド**: 手札を捨て、以降のラウンド不参加
  - **チェック**: 既に最高ベット額を出している場合のみ可能
  - **コール**: 現在の最高ベット額まで合わせる
  - **レイズ**: 最高ベット額を上回る額をベット
  - **オールイン**: 残りチップを全てベット
- アクション制限時間は、通常プレイヤーは betTimeLimit（デフォルト10秒）。
- **親（ディーラー）の場合は dealerTimeLimit（デフォルト20秒）**を適用。
  ※ 配札直後は手札確認のため、考慮時間を多めに確保する。
- 他プレイヤーのアクション中の行動準備可能
- 時間切れで自動フォールド。
- 最後のレイズに対し全員がコール or フォールドでラウンド終了。
- ポットは中央に蓄積表示。

### 4.4 交換（EXCHANGE）
- アクティブな各プレイヤーが、手札から**任意の枚数**（0〜7枚）を選択して交換。
- 捨てた枚数だけ山札から引く。
- 交換は同時に行い、ターンベースではなく「準備完了」方式でOK。

### 4.5 計算・入力フェーズ（CALCULATION）
- **入力時間 = ポットの合計チップ数（秒）**。例: ポットが150なら150秒。
- プレイヤーは以下を行う:
  1. 手札7枚の中から使用するカードを選択（5枚以下、0枚は不可）
  2. 数式を構築（ビジュアルD&D or テキスト入力）
  3. 計算結果を手動で入力
- 時間切れで未提出の場合: 自動的に失格（0点、フォールド扱い）。
- 提出後は待機。全員提出 or 時間切れでショーダウンへ。

### 4.6 ショーダウン（SHOWDOWN）
- フォールドしていないプレイヤーの以下を順に公開:
  - 使用したカード
  - 構築した数式（formulaString）
  - プレイヤーが入力した結果（playerDeclaredResult）
  - **システム計算値（systemEvaluatedResult）**
  - **一致判定マーク（○ or ×）**
- 表示順: プレイヤーが入力した「結果の数値」の**昇順または降順**に並べ替えて縦に展開。各プレイヤーカード横に○×を表示。
- **×のプレイヤーは失格**（計算ミス or 構文エラー）。
- ○のプレイヤーの中で、**評価値が最大**のプレイヤーが勝者。
- 同値の場合: 勝者同士でポットを**山分け**（切り捨て or チップ単位で分割）。

### 4.7 精算（SETTLEMENT）
- 勝者にポットを分配。
- チップが0になったプレイヤーは脱落（トーナメント継続の場合）。
- ハンドカウントを増加させ、レベルアップ間隔に達していればブラインド・アンティを倍にする。
- 生存プレイヤーが1人になるまで、または設定したハンド数に達するまで繰り返す。

## 5. 数式構築システム（最重要）

### 5.1 演算子仕様
| カード   | 入力記号            | 表示記号             | 種別     | 動作      |
| ----- | --------------- | ---------------- | ------ | ------- |
| 1     | `+`             | `+`              | 二項     | 加算      |
| 10    | `*` `×` `＊` `Ｘ` | **`×`**          | 二項     | 乗算      |
| 11    | `^` `＾`         | **`^`**（上付き指数）   | 二項     | べき乗     |
| 12    | `!` `！`         | `!`              | 単項（後置） | 階乗      |
| 13    | `P`             | **`P`**（左下・右上付き） | 二項     | 順列 ₙPᵣ  |
| Joker | `↑↑`            | `↑↑`             | 二項     | テトレーション |


### 5.2 数式ルール
- カード1枚 = 数式内の1要素。連結禁止（例: 2と3をくっつけて23は不可）。
- 括弧 `()` は自由に使用可能。
- 使用カードは5枚以下。
- 構文エラーの数式は無効（ショーダウンで×）。
- 式作成エリア（ビジュアル/テキスト編集タブ）**以外**のすべての画面（プレビュー、ショーダウン、履歴、ログ）では、数式を**数学的な組版**で表示すること。
 ### 表示ルール
 | 構文             | プレーンテキスト  | 表示（HTML/CSS）                    |
| -------------- | --------- | ------------------------------- |
| べき乗 `a^b`      | `5^3`     | `5`<sup>`3`</sup>               |
| 順列 `aPb`       | `5P3`     | <sub>`5`</sub>`P`<sup>`3`<sup> |
| 乗算 `a*b`       | `5*3`     | `5 × 3`                         |
| 階乗 `a!`        | `5!`      | `5!`                            |
| 加算 `a+b`       | `5+3`     | `5 + 3`                         |
| テトレーション `a↑↑b` | `3↑↑3`    | `3↑↑3`                          |
| 括弧             | `(5+3)^2` | `(5 + 3)`<sup>`2`</sup>         |
### 実装方針

-   内部的な評価・パースでは `^` `*` `P` `!` などASCII記号を使用。
    
-   **UI表示層のみ**で `<sup>` / `<sub>` タグ（またはCSS `vertical-align`）を使用して上付き・下付きをレンダリング。
    
-   ネストした場合（例: `(2^3)^2`）も再帰的に適用。
    
-   ショーダウン時の「入力結果」欄も同様の組版で表示。
    
-   スクリーンリーダー対応：aria-label では `5の3乗` `5P3` など読み上げテキストを併記。

### 5.3 計算エンジン要件
- 通常の整数演算はBigIntで扱う。
- 階乗・順列・べき乗・テトレーションは非常に大きくなるため、**桁数比較 or 対数変換による比較**を基本とする。
- プレイヤーが入力した結果と、システムが評価した結果を厳密に比較。一致しなければ×。
- 評価不能（オーバーフロー）の場合も×。桁数が計算可能なら桁数を表示、桁数一致で◯

### 5.4 入力UI — ビジュアル（ドラッグ&ドロップ）
- **game-ui-template-skill.md のカードコンポーネントを使用**。
- 手札エリアに7枚のカードを横並びで表示。クリック or ドラッグで選択。
- **数式構築キャンバス**:
  - 演算子カードをドロップすると、**中央に演算子ノード**が生成され、**左右に数字を入れる枠（スロット）**が出現する。
  - 数字カード or 既存の演算子ノードをスロットにドロップして結合。
  - 数字カードを入れたスロットの**横に新たなスロット**を生成し、そこに別の演算子を置いて連鎖可能にする。
  - `()` はノードを囲むUI上のグループ化機能。ツリー構造で実装。
  - `!` は単項演算子のため、数字ノードの右側にドッキングする特殊UI。
- ツリー全体をリアルタイムでテキスト表現に変換し、テキストタブに反映。

### 5.5 入力UI — テキスト入力
-   入力可能文字
    -   数字: `0-9`
    -   演算子: `+`, `*`, `^`, `!`, `P`, `↑↑`, `(`, `)`
    -   **全角自動変換**:
        -   `＋` → `+`
        -   `×` `＊` `Ｘ`（全角エックス）→ **内部的に `*` に変換。表示は `×`**。
        -   `＾` → `^`
        -   `！` → `!`
        -   `↑` → `↑`
-   テキストエリア内の入力中も、**リアルタイムで `*` を `×` に置換表示**（IME変換後）。カーソル位置を維持すること。
    
-   ビジュアルタブとテキストタブは双方向同期。テキスト側で `5*3` と入力すればビジュアル側では `5 × 3` と表示される。

### 5.6 確認機能
- 提出前に「この数式で確定しますか？」の確認ダイアログを出す。

### 6.3 カードデザイン
- **数字カード（2-9）**: 白背景、中央に大きな数字。シンプル。
- **演算子カード**: 色分けして識別性を高める。表示は演算子
  - `1(+)` : 緑系
  - `10(*)` : 青系
  - `11(^)` : 赤系
  - `12(!)` : 紫系
  - `13(P)` : 橙系
  - `Joker(↑↑)` : 黒金の特別デザイン。アニメーションあり。
- 選択中のカードはスキル準拠の「選択状態」スタイル（枠線発光、少し浮き上がる）。

## 7. インタラクション・アニメーション仕様

- **カード配布**: 山札から各プレイヤー席へカードが飛んでいくアニメーション（0.3秒/枚、 staggered）。
- **チップ移動**: ベット時にチップがポット中央に集まるアニメーション。
- **数式公開（ショーダウン）**: 各プレイヤーの数式がタイピング風に文字表示され、結果がカウントアップされる。
- **○×表示**: 判定結果が出る際に、スケールアップ（バウンド）アニメーション。
- **勝利演出**: 勝者の枠が金色に発光。チップが勝者へ移動するアニメーション。

## 8. その他制約・注意事項

1. **同値判定**: ショーダウンで複数プレイヤーの評価値が完全に一致する場合、ポットを人数で割って分配（端数は切り捨て、余りは次ポットへ持ち越し）。
2. **オールイン**: オールインプレイヤーはポットのメインポットのみを対象とする（サイドポットは実装優先度低）。
3. **CPU（任意）**: 未実装でも可。実装する場合は「ランダムに強そうな数式を組む」程度の簡易AIでOK。
4. **ローカルストレージ**: ゲーム設定、途中経過（ハンド数、チップ状況）は自動保存。ブラウザ更新後も復元可能に。
5. **サウンド**: カード配布音、チップ音、勝利音を最低限実装（game-ui-template-skill.md のオーディオ仕様があれば準拠）。
6. **レスポンシブ**: PC画面をメインとし、タブレット程度まで対応。

## 9. 実装優先順位

1. **P0（必須）**: 設定画面、配札、ベットラウンド、交換、数式テキスト入力、計算エンジン、ショーダウン、精算
2. **P1（重要）**: ドラッグ&ドロップ数式構築UI、テキスト・ビジュアルの双方向同期、全角半角自動変換
3. **P2（追加）**: D&Dの演算子ノード・スロットUI、ポットに応じた入力時間変動、アニメーション演出、CPU対戦
